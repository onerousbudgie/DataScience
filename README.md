# DataScience

My data science learning material and notebooks (Anita Taylor), copied from my
`ProjectsSupportMaterial\BCDataScience` folder.

## Folders

- `Test2020-main/` - deep learning workshop material: Jupyter notebooks
  (perceptron, back-propagation ANN, Keras MNIST sigmoid/deep/CNN, RNN), slides
  and two Excel worksheets. Extracted from `Test2020-main.zip` so the notebooks
  can be read directly on GitHub.
